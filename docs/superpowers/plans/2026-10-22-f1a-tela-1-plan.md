## Global Constraints

- **Next 16:** nunca passar `next/link` (nem componente importado num Server Component) como prop para client component; link em client usa `src/app/cms/(authed)/_shared/cms-link.tsx`. `page.tsx` lê `searchParams` como `Promise`.
- **Server actions:** nenhum client component importa `../actions` nem `../actions-nativo`; o `page.tsx` (server) passa cada action como prop tipada. Toda action nova: `requireEditUser()` no topo (`lib/youtube/ab-lab-acesso.ts`, mesmo critério das demais do Lab, decisão de Yannis registrada no plano irmão), Zod na entrada, `getSupabaseServiceClient()` só depois; todo `where id` leva `site_id` do contexto (id de outro site → `'não encontrado'`).
- Sem `any`; arquivos kebab-case; componentes PascalCase; interfaces com `I` só onde o arquivo vizinho já usa (o Lab usa tipos sem `I`: seguir o vizinho).
- **Cor e forma (M2 README):** um só botão laranja (`pri`) por estado; cada selo = forma + símbolo + palavra (lê-se em cinza); cor = um significado (âmbar ⏸ Lab pausado; verde ✓ registrado/ficou; azul-acinzentado tracejado ▶ em teste no Studio, sólido ● resultado pronto; rosa hachurado ? não medido/formato não confirmado; cinza — sem volume; laranja só no primário). **Sem `color-mix()`**, sem `opacity` em texto (Naksu C1: só a miniatura do contexto a `.6`); tokens literais hex/rgba num CSS do componente com blocos `[data-theme="dark"]` e `[data-theme="light"]` (molde: `_components/faixa-restauracao.css`), valores copiados do `.frame` do mockup (`index.html:26-48`). Texto ≥ 12 px; alvos ≥ 44 px a 390; escala 4/8/12/16/24/32; títulos em Georgia; `overflow-wrap:anywhere` em todo título.
- **Chip de versão (Naksu S2/S3, N4):** `<ChipVersao>` sempre com a letra; cor nunca sem a letra. **Não reusa `VChip`** (`ab-primitives.tsx:17`: texto branco sobre `VARIANT_COLORS` fixo, ~2,5:1 com A = `#FF8240`, `aria-label` em inglês). Tokens com prefixo `--cn-va/--cn-vb/--cn-vc` (a custom property `--vc` inline de `variant-table.tsx:84` tem outro significado e não pode colidir); `aria-label="Versão A"`.
- **Rótulos:** só os do glossário (D-8 e as frases de D-7 incluídas); "variante", "nativo", "detectado", "ficha" (fora do título "Ficha do teste") nunca na tela. "Já iniciei" só do Studio; "Iniciar teste" só do nosso.

- **Prazos:** "Retomar a partir de" = `inicioDoTeste(linha) + 14 d + MARGEM_FECHAMENTO_DIAS (2)` (`nativo/guarda.ts:13,75`), **um instante**: o texto mostra `dd/mm` mais a hora quando ela não for 00:00 ("a partir de 04/11, 22:00", Phil C7); **o botão "Retomar" fica desabilitado enquanto o registro está aberto (dado), não pela data**; a data é só "previsto para", e passada a data com a linha ainda aberta a frase é "Retomar espera o resultado do teste no Studio."
